Real-Time Vehicle Sensor Management System

Interrupt-driven RTOS simulation with deterministic priority scheduling.

This project demonstrates how brake, collision, and speed sensor interrupts are handled using an RTOS-style scheduler, event logging, and safe shared resource management. Use the dashboard to trigger sensors and inspect execution order in real time.
